# RepDB Free Integration Implementation Plan

> **For agentic workers:** Use superpowers:executing-plans or focused delegated tasks to implement this plan. Steps use checkbox syntax for tracking.

**Goal:** Replace mixed exercise content with a complete, consistent, offline RepDB Free catalogue.

**Architecture:** A pinned, validated import generates immutable Dart exercise definitions and bundles only referenced flat-style WebP assets. The UI uses labelled still poses; persistence continues to read existing workout snapshots without a catalogue migration.

**Tech Stack:** Flutter, Dart, existing GetX routing/state, Python import tooling, existing Sembast persistence.

**Spec:** `docs/superpowers/specs/2026-11-08-repdb-design.md`

## Global constraints

- RepDB Free only; source IDs bind instructions and art, no fuzzy matching.
- All referenced flat WebP images bundled offline; premium samples excluded.
- Static pose selection; no video or automatic animation.
- Existing workout records/drafts/photos/units remain untouched.
- Visible linked credit and complete local free-tier license.

## Review focus

- A shared image alias must remain attached to the exact upstream record.
- Single-pose exercises must work without a start/peak pair.
- Every declared illustration must be packaged and decodable offline.
- Historical exercise IDs outside the new catalogue must remain usable in saved sessions/drafts and CSV.
- Small screens and large text must not hide pose selectors, cues or credit links.
